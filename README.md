<h1>ExSDR is a Python SDR Transciver  </h1>
<p>Version 4.1</p>
ExSDR is a receiver and transmitter for a sound-card I/Q radio: your homemade ExSDR board, a HackRF One, or no radio at all, making use of use of your sound device.

Note a test program and there are a number of bugs to work through.

The Digital voice modes are untested on the air, both HxDX14 and HxDX26 have gone through simulation testing.

Update will be posted at future date on this software.

Untested Windows version 4.1, based on the last working Linux version for Ubuntu is available.
